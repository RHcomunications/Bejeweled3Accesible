# Bejeweled 3 Accesible para Android 📱

> **Español** · **English**

## 🇪🇸 Español

Edición accesible de Bejeweled 3 adaptada y optimizada para dispositivos móviles Android con integración nativa para lectores de pantalla (**TalkBack**), orientación apaisada (*Landscape*), efectos y música estéreo de alta calidad y controles táctiles asistidos.

Este repositorio en la rama `android` contiene el **código fuente completo para Android** (.NET 9 Android) y publica los paquetes **APK firmados** listos para instalar.

### 📥 Descargar APK
Ve a la sección de [Releases de Android](../../releases?q=android) y descarga el archivo `.apk` de la versión más reciente.

### 📱 Requisitos
- Dispositivo Android 5.0 (Lollipop / API 21) o superior.
- Lector de pantalla **TalkBack** activado (o cualquier lector de pantalla compatible).

### 🎮 Cómo jugar en Android
1. Instala el archivo `.apk` en tu dispositivo Android.
2. Abre **Bejeweled 3 Accesible**.
3. Sostén el teléfono de forma **horizontal (apaisada)**.
4. **Navegación por Menús**:
   - Desliza hacia abajo para ir a la siguiente opción.
   - Desliza hacia arriba para ir a la opción anterior.
   - Toca dos veces o pulsa sobre la opción para entrar.
   - Desliza hacia la izquierda para volver al menú anterior.
5. **En Partida**:
   - El tablero 8x8 se muestra amplio en la parte izquierda.
   - Toca cualquier gema: TalkBack te dirá sus coordenadas, color y si tiene movimientos válidos disponibles (ej. *"C4: Gema Roja. Puedes mover hacia la derecha o abajo"*).
   - Desliza sobre la gema hacia la dirección deseada para intercambiarla.
   - En el panel lateral derecho dispones de botones accesibles para pedir **Pista (💡 HINT)** y abrir el menú de **Pausa (⏸️ PAUSA)**.

## 🇬🇧 English

Accessible edition of Bejeweled 3 adapted for Android mobile devices with native screen-reader support (**TalkBack**), landscape layout, full stereo sound & music, and assisted touch controls.

This repository branch (`android`) contains the **Android source code** (.NET 9 Android) and published **signed APKs**.

### 📥 Download APK
Go to the [Android Releases](../../releases?q=android) tab and download the latest `.apk` package.

### 📱 Requirements
- Android 5.0 (API 21) or higher.
- **TalkBack** screen reader (or compatible accessibility service).

### 🎮 How to Play on Android
1. Install the `.apk` file on your device.
2. Open **Bejeweled 3 Accessible**.
3. Hold your phone in **Landscape mode**.
4. **Menu Navigation**:
   - Swipe down for next item.
   - Swipe up for previous item.
   - Double-tap or tap to select.
   - Swipe left to go back.
5. **Gameplay**:
   - The 8x8 board is on the left.
   - Tap any gem: TalkBack announces coordinates, color, and valid move directions.
   - Swipe in the direction you want to swap.
   - Use the right-side panel for **Hint (💡)** and **Pause (⏸️)** buttons.
