# Bejeweled 3 Accesible para Windows 💻

> **Español** · **English**

## 🇪🇸 Español

Edición accesible de Bejeweled 3 adaptada y optimizada para **Windows** con integración nativa para lectores de pantalla (**NVDA** y la voz de Windows), efectos y música estéreo de alta calidad con **audio binaural 3D por objetos**, y controles íntegramente por teclado.

Este repositorio en la rama `main` contiene el **código fuente completo para Windows** (.NET Framework 4.5 / C# 5) y publica el paquete **ZIP autocontenido** listo para ejecutar.

### 📥 Descargar (Windows)
Ve a la sección de [Releases](../../releases) y descarga el archivo `.zip` de la versión más reciente (marcada como **Latest**). Descomprime y ejecuta `Bejeweled3Accessible.exe`.

### ⌨️ Requisitos
- Windows 7 o superior.
- Lector de pantalla **NVDA** (o la voz de Windows) activado.
- .NET Framework 4.5 (presente por defecto en la mayoría de sistemas).

### 🎮 Cómo jugar en Windows
1. Descomprime el `.zip` y ejecuta `Bejeweled3Accessible.exe`.
2. Abre **Bejeweled 3 Accesible**.
3. **Navegación por Menús**: usa las Flechas + Intro; Escape vuelve al menú anterior.
4. **En Partida**:
   - Mueve el cursor con las **Flechas direccionales** (de A1 a H8); se anunciará la casilla y el color/tipo de gema, y su sonido se oirá a la izquierda o a la derecha según la columna (audio binaural).
   - Intercambia con **W / A / S / D** (arriba / izquierda / abajo / derecha).
   - **R** consulta el estado; **Q** el progreso de la misión; **C** repite la casilla; **H** da una pista.
5. La música real del juego (módulo `Bejeweled3_suite.mo3`) y los 189 efectos oficiales suenan espacializados; en Opciones puedes elegir entre los perfiles espaciales (Escenario 2D, Clásico Limpio, Simple u Objeto 3D / Atmos).

## 🇬🇧 English

Accessible edition of Bejeweled 3 adapted for **Windows** with native screen-reader support (**NVDA** and the Windows voice), full stereo sound & music with **object-based 3D binaural audio**, and full keyboard controls.

This repository branch (`main`) contains the **Windows source code** (.NET Framework 4.5 / C# 5) and publishes a self-contained **ZIP** package.

### 📥 Download (Windows)
Go to the [Releases](../../releases) tab and download the latest `.zip` (marked **Latest**). Unzip and run `Bejeweled3Accessible.exe`.

### ⌨️ Requirements
- Windows 7 or higher.
- **NVDA** screen reader (or Windows voice) enabled.
- .NET Framework 4.5.

### 🎮 How to Play on Windows
1. Unzip and run `Bejeweled3Accessible.exe`.
2. Open **Bejeweled 3 Accessible**.
3. **Menu Navigation**: Arrow keys + Enter; Escape goes back.
4. **Gameplay**:
   - Move the cursor with the **Arrow keys** (A1 to H8); the gem's coordinates, color and valid moves are announced, and its sound is panned left/right by column (binaural audio).
   - Swap with **W / A / S / D** (up / left / down / right).
   - **R** status; **Q** mission progress; **C** repeat cell; **H** hint.
5. The real game music (MO3 module) and 189 official effects play spatially; in Options pick a spatial profile (Stage 2D, Clean Arcade, Simple or 3D Object / Atmos).
